# First Bike Moto Mod

A DIY project that adds motorcycle-inspired sound, lights, and controls to a FirstBIKE balance bike.

퍼스트바이크에 시동음, LED, 스위치를 추가해 작은 오토바이처럼 만들어보는 DIY 프로젝트입니다.

🌐 **[View the build log / 제작기 보기](https://moonkongv2.github.io/first-bike-moto-mod/)**

🎬 **[Watch the finished bike on Instagram / 완성 모습 보기](https://www.instagram.com/reel/Dcsc5PiyJVf/)**
