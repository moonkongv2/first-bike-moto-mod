# First Bike Moto Mod

A DIY project that adds motorcycle-inspired lights, sound, and controls to a FirstBIKE balance bike.

퍼스트바이크에 시동음, LED, 스위치를 추가해 작은 오토바이처럼 만들어보는 DIY 프로젝트입니다.

## Project Idea

The idea started with a simple goal: make a balance bike feel a little more like a real motorcycle.

The bike is being upgraded with:

- a switch for a motorcycle-like ignition experience
- an engine start sound using Arduino Nano + DFPlayer Mini
- LED lighting
- a compact battery-powered circuit
- an enclosure designed for outdoor use

기능 자체는 단순하지만, 실제 자전거에 설치하기 위해 회로 설계뿐 아니라 전원 안정성, 배선, 납땜, 부품 배치, 방수, 스피커 음량 등 여러 가지를 함께 고민하고 있습니다.

## Main Components

- Arduino Nano
- DFPlayer Mini
- microSD card
- Speaker
- LED strip
- Switch
- 3.7 V battery
- DC-DC converter
- Fuse
- PWM dimmer
- ABS enclosure
